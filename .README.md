# Claims Reserving Model

A model applying two core actuarial reserving methods to project outstanding insurance claims.

## Methodology

Models outstanding claims reserves across six accident years using:
- **Chain-Ladder method:** projects future claims development based on historical payment patterns
- **Bornhuetter-Ferguson (BF) method:** blends historical development patterns with prior expected loss ratios, reducing sensitivity to volatile early-year data

## Dependencies

- Microsoft Excel (and relevant in-Excel formulae)

## Limitations

Does not account for other possible events which could naturally occur as part of the insurance industry/process such as:
- Reinsurance recoveries
- Unstable inflation for claims

## Next steps

Stress testing under these adverse scenarios, e.g. interest rate shocks.
